**English:**
# ☕ Java Basics

Welcome to my Java learning repository! Here you will find practical exercises to consolidate the fundamentals of the language, focusing on mathematical operations and basic logic.

![Java](https://img.shields.io/badge/java-%23ED8B00.svg?style=for-the-badge&logo=openjdk&logoColor=white)

## 📂 Included Exercises

Currently, the repository contains the following programs:

* **`ConvertirTemperatura.java`**:
    * A program to practice arithmetic operators by converting temperatures (e.g., Celsius to Fahrenheit).
* **`HoresMinutsSegons.java`**:
    * An exercise for converting time units (Hours, Minutes, Seconds).
* **`Quadrat.java`**:
    * Basic geometric calculations area or perimeter using variables.
* **`preu.java`**:
    * Cost calculation, applying taxes or discounts.
